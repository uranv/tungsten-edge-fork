# Fork 更新日志（基于 v0.18.4）

- 添加「固定窗口卡片宽度」功能，选项位于状态栏菜单，默认关闭。开启后，所有带标题的窗口卡片使用相同的标题区域宽度。
- 添加窗口卡片宽度滑块，位于状态栏菜单的「Dock 栏大小」下方。未开启固定宽度时显示「窗口卡片最大宽度」，开启后显示「窗口卡片宽度」。调节范围为 40–140 pt，步长为 1 pt；默认值为 140 pt，与原有标题区域宽度上限一致。
- 窗口卡片宽度控制通过修改原有标题区域宽度计算实现。

原计算方式：

```text
标题区域宽度 = ceil(min(文字测量宽度, 140 × scale))
```

修改为：

```text
标题区域宽度 = ceil(fixedWidth ? (maximumWidth × scale) : min(文字测量宽度, maximumWidth × scale))
```

其中，`fixedWidth` 表示是否固定宽度，`maximumWidth` 为滑块设置的标题区域基准宽度，`scale` 为 Dock 大小的缩放系数。

卡片总宽度仍由标题区域、图标槽位、间距和内边距组成，其余宽度计算规则沿用原有逻辑，随新的标题区域宽度自动更新。默认配置为 `fixedWidth = false`、`maximumWidth = 140`，保持原有显示行为。
